# Example Scripts

This directory contains example scripts for using the `revolab` library.

## `calculate_mos_scores.py`

This script is a utility for batch-calculating Mean Opinion Scores (MOS) for a directory of audio files.

### Note on Dependencies

This script requires a private/local library named `sidon_recon`, which is not publicly available. To run this script, you must provide this library and ensure it is available in your Python environment.

The script also requires the `tqdm` library.
